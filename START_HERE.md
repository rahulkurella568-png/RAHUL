## 🔄 QUICK PROCESS OVERVIEW

### P2P Summary
```
Req → PO → Receipt → Invoice → Match → Approve → Pay → Reconcile
      │
      └─ GL: Encumb → Accrual → Inventory/Expense → AP → Cash
```

### O2C Summary
```
SO → Credit Check → Shipment → Invoice → Revenue Recognition → Collection → Reconcile
                                │
                                └─ GL: COGS → Revenue → AR → Cash
```

### Integration
```
P2P Payments ←→ O2C Collections → Cash Management → GL Consolidation → Financial Statements
```
