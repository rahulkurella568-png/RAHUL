🎯 QUICKEST METHOD: USE YOUR BROWSER (30 SECONDS)
═════════════════════════════════════════════════════════════════════════

This is the EASIEST and FASTEST way to create a professional PDF!

WINDOWS:
  1. Download: P2P_O2C_CYCLES_GUIDE.html from GitHub
  2. Right-click file → Open with → Chrome (or Firefox/Edge)
  3. Press: Ctrl + P
  4. In Print dialog:
     - Change printer to "Save to PDF" or "Print to File"
     - Click "Save"
  5. Choose location and filename
  6. Done! ✓ Professional PDF created

MAC:
  1. Download: P2P_O2C_CYCLES_GUIDE.html from GitHub
  2. Double-click to open in Safari (or Chrome/Firefox)
  3. Press: Cmd + P
  4. Click "PDF" dropdown at bottom left
  5. Select "Save as PDF"
  6. Choose location and filename
  7. Done! ✓ Professional PDF created

LINUX:
  1. Download: P2P_O2C_CYCLES_GUIDE.html from GitHub
  2. Open with: firefox P2P_O2C_CYCLES_GUIDE.html
  3. Press: Ctrl + P
  4. Select "Print to File" or PDF printer
  5. Save with filename: P2P_O2C_Cycles_with_DataStructures.pdf
  6. Done! ✓

❓ TROUBLESHOOTING:
═════════════════════════════════════════════════════════════════════════

Problem: File won't open
Solution: Make sure you downloaded the .html file, not .md
Try: Right-click → Open with → Choose browser

Problem: PDF looks wrong/missing colors
Solution: Check "Background graphics" checkbox in print dialog
Try: Use Chrome instead of Edge

Problem: PDF too large
Solution: This is normal (50-100 MB is typical)
Try: Compress PDF with: https://www.ilovepdf.com/compress_pdf

Problem: Printing to PDF not working
Solution: Install a PDF printer:
  Windows: Already built-in (Print to PDF)
  Mac: Already built-in (Save as PDF)
  Linux: Install: sudo apt-get install cups-pdf
